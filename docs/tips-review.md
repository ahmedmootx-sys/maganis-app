# مراجعة نصائح د. مجانص (Coach Tips Review)

تم استخراج كافة النصائح والرسائل التوجيهية الخاصة بـ «د. مجانص» بدون أي تعديل لمراجعتها:

## نصائح لوحة التحكم اليومية (Dashboard Daily Tips)

| معرف النصيحة (ID) | نص النصيحة (Tip Text) |
| :--- | :--- |
| `tip-1` | يا أسطى العضلات! د. مجانص بيقولك: اللي يفوّت تمرين الرجلين يروح يتمرن زومبا أحسن! الأرجل هي أساس هرمون التستوستيرون يا بطل! |
| `tip-2` | البروتين ثم البروتين! سيبك من الفسيخ والمقليات وركّز في الفراخ والبيض والتونة، عشان الألياف العضلية تبات شبعانة وتصحى عملاقة! |
| `tip-3` | عاش يا وحش! الالتزام بالتحميل التصاعدي وزيادة الأوزان حبة حبة هو سر الفورمة.. البار بيستغيث والدهون بتعيط! |
| `tip-4` | النوم 8 ساعات مش كسل، دي الفترة الوحيدة اللي د. مجانص بيبني فيها عضلاتك في المعمل! متسهرش قدام التيك توك وتطلب فورمة! |
| `tip-5` | الماء يا كوتش! اشرب من 3 إلى 4 لتر مية يومياً.. مفيش بمب عضلات من غير هيدريشن عالي يا صديقي! |
| `tip-6` | د. مجانص شايفك وانت بتبص على الشاورما! لو هتاكل، احسبها في الماكروز وسف السعرات بالتمرين، كل حاجة بالعلم بتتحل! |
