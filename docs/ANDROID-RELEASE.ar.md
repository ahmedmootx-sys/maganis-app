# دليل بناء وتثبيت وتحديث تطبيق مجانس على أندرويد (دليل المالك)

هذا الدليل مكتوب بالعامية المصرية البسيطة خطوة بخطوة، بأوامر جاهزة للنسخ، لتثبيت تطبيق مجانس كأبلكيشن أندرويد حقيقي وتحديثه بأمان من غير ما تفقد بياناتك أبداً.

---

## 1. الإعداد لأول مرة فقط (One-Time Setup)

هتعمل الخطوات دي مرة واحدة فقط في البداية:

### أ) تثبيت جافا (JDK 21)

1. نزل وثبت JDK 21 من موقع تيمورين الرسمي:
   https://adoptium.net/temurin/releases/?version=21
2. وأنت بتثبت على ويندوز، اختار تفعيل خيار **"Set JAVA_HOME"** وخيار **"Add to PATH"**.

### ب) توليد مفتاح التوقيع (Release Keystore)

افتح موجه الأوامر في مجلد المشروع وشغل:

```bash
npm run android:keystore
```

السكريبت هيعمل الآتي:

- هيولد ملف الكي ستور السري في مجلد بره المشروع خالص في حسابك الشخصي: `~/maganis-keystore/`.
- هيطبعلك بصمة الشهادة (SHA-256 Fingerprint).
- هيجهزلك ملف الأسرار وفيه كلمات السر القوية اللي اتولدت عشوائياً.

> ⚠️ **تحذير أمني واستقرار حرج جداً:**
> احتفظ بنسخة من مجلد `maganis-keystore` في فلاشة خارجية أو مكان آمن.
> لو المفتاح ده ضاع، مش هتقدر تحدث التطبيق على تليفونك مستقبلاً، وهتضطر تمسحه وتثبته من أول وجديد وده هيمسح بياناتك!

### ج) إضافة الأسرار على GitHub

ادخل على المتصفح وافتح صفحة مشروعك على GitHub ثم ادخل على:
**Settings ➔ Secrets and variables ➔ Actions**

1. في تبويب **Variables** (المتغيرات):
   - اضغط **New repository variable**.
   - الاسم: `ANDROID_CERT_SHA256`
   - القيمة: بصمة SHA-256 اللي طبعها السكريبت في الخطوة السابقة.

2. في تبويب **Secrets** (الأسرار):
   - اضغط **New repository secret** وأضف الـ 4 أسرار دي (موجودين داخل `maganis-keystore-secrets.txt`):
     - `ANDROID_KEYSTORE_PASSWORD`
     - `ANDROID_KEY_ALIAS`
     - `ANDROID_KEY_PASSWORD`
     - `ANDROID_KEYSTORE_BASE64` (انسخ محتوى الملف `maganis-keystore-base64.txt` كاملاً وضعه هنا).

---

## 2. إطلاق إصدار جديد (Cut a Release)

كل ما تعوز تطلع نسخة رسمية جديدة للتليفون:

1. افتح ملف `package.json` وغير رقم الإصدار (مثلاً من `"0.1.0"` لـ `"0.2.0"`).
2. افتح ملف `CHANGELOG.md` واكتب التغييرات الجديدة تحت عنوان الإصدار الجديد (مثلاً `## [0.2.0] - 2026-11-01`).
3. نفذ الأوامر التالية بالترتيب:

```bash
git add package.json CHANGELOG.md
git commit -m "chore: release v0.2.0"
git tag v0.2.0
git push origin main
git push origin v0.2.0
```

4. افتح تبويب **Actions** على GitHub واستنى لحد ما الورك فلو الأخضر يخلص (هتلاقي الإصدار اتبنى واتوقع أوتوماتيك ونزل في صفحة Releases).

---

## 3. تثبيت التطبيق لأول مرة على التليفون

1. افتح متصفح جوجل كروم على تليفون الأندرويد وادخل على صفحة الـ Releases في مشروعك:
   `https://github.com/ahmedmootx-sys/maganis-app/releases`
2. حمل ملف الـ APK الرسمي (مثلاً `maganis-0.2.0.apk`).
3. اضغط على الملف بعد ما ينزل. لو المتصفح قالك "غير مسموح بتثبيت تطبيقات غير معروفة":
   - ادخل على الإعدادات من الرسالة وفعل خيار: **"السماح بتثبيت التطبيقات من هذا المصدر"** (Allow from this source).
4. لو ظهرت رسالة حماية جوجل (Google Play Protect) بتقول: «Blocked by Play Protect» أو «Unrecognised app»:
   - اضغط على **"More details"** (تفاصيل إضافية).
   - بعدين اضغط على **"Install anyway"** (التثبيت على أي حال).
5. افتح التطبيق، هتلاقيه اشتغل فوراً، مظبوط في الوضعين الفاتح والداكن، وأوفلاين تماماً.

---

## 4. تحديث التطبيق مع الحفاظ على البيانات

لما تطلع إصدار أحدث (مثلاً `v0.2.1`):

1. حمل الـ APK الجديد من صفحة Releases على التليفون.
2. اضغط عليه واختار **تحديث (Update)**.
3. التحديث هيتثبت **فوق النسخة القديمة مباشرة** بدون مسح أي تمرين، وبدون مسح الملف الشخصي، لأن مفتاح التوقيع متطابق!

---

## 5. ماذا تعني رسالة "App not installed" (التطبيق ليس مثبتاً)؟

لو ظهرتلك رسالة الخطأ دي أثناء محاولة التثبيت، بيكون سببها غالباً حاجة من اتنين:

1. **اختلاف مفتاح التوقيع (Signature mismatch):** التليفون عليه نسخة تجريبية (Debug) أو متوقعة بمفتاح تاني، وبتحاول تثبت فوقها نسخة Release.
2. **رقم النسخة أقل (Downgrade):** بتحاول تثبت نسخة برقم `versionCode` أقل من النسخة اللي راكبة على التليفون.

> 🔴 **القاعدة الذهبية رقم 1 لحماية بياناتك:**
> **إياك تمسح التطبيق من التليفون قبل ما تعمل ملف نسخ احتياطي!**
> ادخل أولاً على الإعدادات ➔ «البيانات والمزامنة» ➔ «تصدير نسخة احتياطية»، واحفظ الملف على التليفون أو ابعته لنفسك على تيليجرام/إيميل. بعد كده لو اضطررت تمسح التطبيق، هتقدر تسترجع كل بياناتك في ثواني بضغطة زر واحدة.
