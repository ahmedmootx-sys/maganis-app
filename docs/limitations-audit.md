## 2. الخلاصة والحكم (Conclusion)

كما توقعت وثيقة TASK G بدقة:

1. السؤال السابق «هل لديك إصابة أو حالة صحية تؤثر على التمرين؟» كان يحفظ قيمة منطقية (نعم/لا) مع نص حر دون أي ربط تشريحي أو تصنيف للأحمال.
2. لا يوجد أي تأثير لحقل الإصابات على استبعاد التمارين أو اقتراح بدائل أخف أو تنبيه المتدرب قبل بدء الجلسة أو أثناء تسجيل الألم في الجلسة.
3. **الحل في Task G**:
   - بناء هيكل بيانات القيود `limitations: [{ region, status, note }]` مع `redFlag: boolean`.
   - المناطق التشريحية الثمانية المعتمدة مع الحالات الثلاث.
   - ملف أحمال المناطق للتمارين `data/exercise-region-load.json`.
   - شارات التحذير الملونة، تنبيه ما قبل الجلسة، تسجيل الألم «ألم؟»، والبدائل المنسقة.
