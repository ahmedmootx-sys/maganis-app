# مصفوفة تكافؤ الميزات وعناصر التحكم (Feature Parity Matrix)

> **قاعدة صارمة:** لا يُسمح بحذف أو تقليص أو فقدان أي ميزة أو زر أو عنصر تحكم من النظام الحالي. يتم توثيق موقع كل عنصر تحكم وتأكيد وجوده بنسبة 100% دون أي فقدان وظيفي.

  - [x] **الأهداف والتغذية:** رابط لحاسبة السعرات ومستهدفات الماكروز.
  - [x] **التدريب:** بداية الأسبوع (`weekStartDay` الافتراضي السبت)، وقت الراحة الافتراضي، الوحدات.

  - [x] **البيانات والمزامنة:** حالة ملف المزامنة، حفظ نسخة احتياطية، استيراد، مشاركة، وتصدير/استيراد التقارير.

## 13. معالج التهيئة الأولى (First-Run Wizard - 6 Steps)

- [x] **مسار كامل للشاشة دون شريط سفلي وبدون هيدر التطبيق العادي:**
  - [x] شريط التقدم العلوي `WizardProgress` فقط.
  - [x] أيقونة د. مجانص 72px تظهر لمرة واحدة في الخطوة الأولى مع سطر ترحيبي مقتضب، وتظهر مجدداً في الخطوة الأخيرة فقط.
  - [x] إزالة أي شعارات إضافية، بطاقات شارات PRODUCTION، أو مفاتيح المظهر المشتتة.
  - [x] شريط سفلي لاصق: زر رئيسي «التالي» (معطل حتى استيفاء الحقل، وفي الخطوة الأخيرة: «حفظ والبدء») وزر فرعي «رجوع».
  - [x] استئناف المسودة تلقائياً عند إعادة تحميل الصفحة في نفس الخطوة وبنفس الإجابات.
- [x] **الخطوة 1: «ما هدفك؟»:** قائمة `OptionList` للأهداف (تضخيم، تنشيف، مرونة، كاليستينكس) مع الحفاظ على النصوص الدقيقة.
- [x] **الخطوة 2: «تدريبك»:**
  - [x] صف واحد من أزرار الاختيار متساوية العرض `ToggleChips` لأيام التدريب من 2 إلى 6 أيام (بدون أزرار يتيمة).
  - [x] حقول إضافية اختيارية: خبرة التدريب (مبتدئ / متوسط / متقدم)، مكان التدريب (جيم / منزل / الاثنان)، والاسم.
- [x] **الخطوة 3: «صحتك»:**
  - [x] السؤال: «هل لديك إصابة أو حالة صحية تؤثر على التمرين؟».
  - [x] مفتاح `Segmented` بخيارين (نعم / لا)، وحقل تفاصيل إضافي عند اختيار "نعم".
  - [x] إخلاء المسؤولية الطبية كـ `Callout` وقائي هادئ.
- [x] **الخطوة 4: «جسمك»:**
  - [x] الجنس كمفتاح `Segmented` (ذكر / أنثى).
  - [x] حقول العمر والطول والوزن مع لواحق الوحدات (سنة، سم، كجم)، مع التحقق اللحظي ولوحات الأرقام الملائمة.
- [x] **الخطوة 5: «نشاطك اليومي»:**
  - [x] المستويات الخمسة للنشاط كـ `OptionList` مع العنوان والوصف التفصيلي، ومعامل الضرب (مثل `x1.55`) كتاج LTR صغير بدون إقحامه في العنوان.
- [x] **الخطوة 6: «مراجعة»:**
  - [x] `KeyValueList` يعرض ملخص الإجابات (الهدف لمرة واحدة، الأيام، الصحة، الجنس، العمر، الطول، الوزن، والنشاط).
