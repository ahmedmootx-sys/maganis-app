# مصفوفة تكافؤ الميزات وعناصر التحكم (Feature Parity Matrix)

> **قاعدة صارمة:** لا يُسمح بحذف أو تقليص أو فقدان أي ميزة أو زر أو عنصر تحكم من النظام الحالي. يتم توثيق موقع كل عنصر تحكم قبل التعديل وموقعه الجديد في نظام التصميم بعد التعديل.

| عنصر التحكم القديم (Old Control) | نوعه وسلوكه القديم | الموقع الجديد في نظام التصميم (New Location) | الحالة |

| **أيام الأسبوع التدريبية** | كروت مكدسة تحتوي على تفاصيل مشتتة | **ListRows للأسبوع:** (اليوم، التركيز العضلي، عدد التمارين، الحالة)؛ يوم اليوم يحمل مؤشر تمييز (accent)، والضغط يفتح شاشة اليوم | مكتمل |
| **شاشة اليوم (Day Screen)** | صفحة منفصلة أو عرض عميق مع أزرار متفرقة | **Day Screen كاملة:** TopBar مع زر رجوع (العنوان = اليوم، الثانوي = التركيز). قسمين: «الإحماء والتسخين» و«التمارين الأساسية» مع العدادات، والقسم الفارغ يظهر سطر وزر فرعي «إضافة». صفوف التمارين مع مصغرات 56px، اسم عربي حتى 3 أسطر، ثانوي إنجليزي ltr، وتفاصيل المجموعات. الزر الرئيسي اللاصق بالأسفل «ابدأ التمرين» | مكتمل |
| **إجراءات اليوم (تحويل لمنزلي، إضافة، ترتيب)** | 4-5 أزرار صغيرة بكل صف أو أعلى الجدول | **قائمة الإجراءات في الشيت:** خيارات «تحويل لمنزلي»، «إضافة تمرين»، «ترتيب وتعديل» في الـ Sheet؛ ونمط التعديل يعرض مقابض السحب والحذف | مكتمل |
