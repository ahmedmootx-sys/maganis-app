# قائمة التحقق بالمحاكاة للأجهزة الميدانية (Emulation Device Checklist — Task G)

> **المشروع**: تطبيق مجانيس (<bdi dir="ltr">Maganis</bdi>) — مدرب اللياقة والتغذية العربي (RTL, Mobile-first, Local-first).  
> **حالة التحقق**: موثق في المحاكاة (Verified in Emulation) وفق القاعدة الصارمة R13.  
> **بيئات وأبعاد المحاكاة (R14)**:
> - الشاشة الأساسية: <bdi dir="ltr">360×720</bdi> (Android Chrome Mobile, DPR 2).
> - الشاشات الثانوية: <bdi dir="ltr">360×640</bdi>، <bdi dir="ltr">412×892</bdi> (Pixel 7 / Galaxy S series, DPR 2 / DPR 2.6).
> - مقياس الخط: 1.0 و 1.3 (<bdi dir="ltr">Accessibility Large Text</bdi>).
> - السمات: السمة الفاتحة (<bdi dir="ltr">Light Mode</bdi>) والسمة الداكنة (<bdi dir="ltr">Dark Mode</bdi>).
> - اتجاه الواجهة: عربي أصيل من اليمين لليسار (<bdi dir="ltr">RTL</bdi>).

---

## 1. حالة الجهاز والهيكل البرمجي (Device State Knowable & Shell)

- [x] **معرف البناء والنسخة الحية**:
  - عرض معرف البناء <bdi dir="ltr">`__BUILD_ID__`</bdi> والوقت الزمني الحقيقي للبناء في شاشة التشخيص <bdi dir="ltr">DiagnosticsSheet</bdi> (تم التحقق في المحاكاة).
  - ملف <bdi dir="ltr">`version.json`</bdi> يتم توليده آلياً ومزامنته بدون تخزين مؤقت (`no-store`) (تم التحقق في المحاكاة).
  - تسجيل عامل الخدمة (<bdi dir="ltr">Service Worker</bdi>) مع تفعيل الإلغاء الفوري للانتظار (`skipWaiting`) والسيطرة الفعالة على العملاء في التحميل الثاني (تم التحقق في المحاكاة: Gate 5.9).
- [x] **علامة التطبيق التجارية الموحدة**:
  - الشريط العلوي يلتزم بالاسم اللاتيني الصريح المعزول `<bdi dir="ltr">Maganis</bdi>` و 0 تكرارات مشوهة أو متضاربة في واجهة المستخدم (تم التحقق في المحاكاة: `docs/brand-occurrences.md`).
- [x] **لوحة التشخيص الميداني (DiagnosticsSheet)**:
  - تضمين 16 حقلاً تشخيصياً تشمل: حالة عامل الخدمة، الذاكرة المستخدمة، التخزين المحلي، أبعاد نافذة العرض، اتجاه النصوص، ومعرف الجلسة الحالية (تم التحقق في المحاكاة).

## 2. عقود التخطيط ومسافات الأمان (Layout Insets & Boundaries)

- [x] **عقد حواف الشاشة (Layout Insets >= 12px)**:
  - خلو كامل لكافة الشاشات السبع الرئيسية ومكتبة التمارين من التصاق العناصر بحواف الشاشة (تم فحص 369 عنصراً ميدانياً في المحاكاة عبر Gate 5.1 مع 0 مخالفات).
- [x] **عقد أزرار الخيار والتفضيل (Choice Buttons Contract)**:
  - كافة أزرار الاختيار تلتزم بدور إمكانية الوصول الصريح (`role="radio"` أو `role="checkbox"` أو `role="tab"`) وسمة `aria-checked` الدقيقة (تم فحص 62 عنصراً عبر Gate 5.2 مع 0 مخالفات).
  - تباين الألوان للحالة المحددة يتجاوز 3:1 للمؤشرات والحدود، و 4.5:1 للنصوص (تم التحقق في المحاكاة).
- [x] **عقد حدود الأزرار والحالة المعطلة (Button Visual Contract)**:
  - الأزرار المعطلة تلتزم بعتامة 100% (`opacity: 1`) واستخدام رمز السطح الصلب المخصص للمعطل بدلاً من تبهيت العنصر (تم فحص 422 زراً عبر Gate 5.3 مع 0 مخالفات).
- [x] **أبعاد أهداف اللمس (Touch Target Geometry >= 44x44px)**:
  - عناصر الشريط العلوي محققة لمساحة لمس لا تقل عن <bdi dir="ltr">40×40px</bdi> وتباعد لا يقل عن <bdi dir="ltr">8px</bdi> (تم التحقق في المحاكاة: Gate 5.5).
  - ألسنة شريط التنقل السفلي محققة لمساحة لمس <bdi dir="ltr">44×44px</bdi> على الأقل وحاوية المحتوى مزودة بحاشية سفلية تعادل ارتفاع الشريط السفلي مضافاً إليه حاشية أمان الشاشة السفلية <bdi dir="ltr">`env(safe-area-inset-bottom)`</bdi> لمنع حجب أي محتوى نهائياً (تم التحقق في المحاكاة: Gate 5.5).

## 3. نزاهة التغذية ومصدر الحقيقة الموحد (Nutrition Truth & computeEnergyPlan)

- [x] **توحيد محرك الحساب عبر `computeEnergyPlan`**:

- [x] **مؤشر النسبة المتناسق `<Ratio>`**:
  - عرض الماكروز والتوزيع الطاقي بدقة متناهية مع نسبة الإنجاز اليومي.
- [x] **وحدة الجرام الصريحة «جم»**:
  - 100% من الوحدات الغذائية مكتوبة بالرسم العربي الموحد «جم» دون أي ظهور لكلمة «جرام» أو الحرف اللاتيني `g` (تم التحقق في المحاكاة: Gate 5.4).
- [x] **تنظيف النصوص التغذوية**:
  - إزالة النقطتين الرأسيتين اللاحقة (:).
  - استبدال «حساب EAT» بالمصطلح الرياضي الواضح «حساب حرق التمرين».
  - استبدال «نشاط #1» بالصياغة العربية النظيفة «النشاط 1».
